Amazon Clone

An Amazon-inspired e-commerce web application built using React.js. This project replicates core shopping platform functionalities such as product browsing, cart management, routing, and responsive user interface design.

GitHub Repository

🔗 Repository: https://github.com/kallamadiyashwanth/amazon-clone

Features:
-> Responsive Amazon-style user interface
-> Product listing and browsing
-> Add-to-cart functionality
-> Cart state management
-> Dynamic data rendering through API integration
-> Client-side routing using React Router
-> Reusable React components
-> Modern frontend architecture
